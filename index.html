文件直接提交到你自己的 GitHub 仓库，由 GitHub Pages 对外提供访问。
令牌只保存在这台电脑的浏览器里，只会发往 api.github.com，不经过任何第三方。

新建的仓库一般是 main，老仓库可能是 master。填错会报 404。
去 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens： Repository access 只勾这一个仓库，Permissions → Contents 设为 Read and write。 别用 classic token 的全权限，泄露了整个账号都完蛋。
